# CS300-DSA-Analysis-and-Design

## Course Description
Students will develop code and use non-coding development methodologies in algorithmic design and problem solving.
Students will use advanced algorithmic designs to evaluate complex data structures to aid in problem solvin


### What was the problem you were solving in the projects for this course?
Throughout this course, I developed an academic advising system that could read course information from a CSV file, validate prerequisites, allow users to search for individual courses, and print all courses in alphanumeric order. The project required me to compare vectors, hash tables, and binary search trees to determine which data structure would provide the most efficient solution.

### How did you approach the problem? Consider why data structures are important to understand.
I approached the project by breaking it into smaller tasks and creating pseudocode before writing code. I analyzed the strengths and weaknesses of vectors, hash tables, and binary search trees to understand how each would affect performance. This course showed me that choosing the right data structure is important because it directly impacts how quickly data can be stored, organized, and retrieved. Understanding these trade-offs helped me make better design decisions throughout the project.

### How did you overcome any roadblocks you encountered while going through the activities or project?
My biggest challenges involved implementing the binary search tree, validating prerequisite courses, and debugging issues with course searches and output formatting. I overcame these problems by testing one function at a time, reviewing the project requirements carefully, and using my pseudocode to trace the program's logic. Although debugging could be frustrating, it helped me become more patient and improved my problem-solving skills.

### How has your work on this project expanded your approach to designing software and developing programs?
This project taught me the importance of planning before coding. Instead of jumping directly into implementation, I learned to evaluate different solutions, consider runtime performance, and think about future requirements. Comparing multiple data structures helped me understand that software design decisions can significantly affect both performance and usability.

### How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
This project encouraged me to write cleaner and more organized code by separating tasks into specific functions, using meaningful variable names, and creating a clear menu-driven structure. I also gained a better understanding of how thoughtful design choices make programs easier to maintain and modify. As a result, I now focus more on readability, efficiency, and adaptability when developing software.
